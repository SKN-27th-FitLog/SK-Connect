### 대상 파일

common/

## 2. 저장 경로 규칙

최종 저장 경로는 아래 형태를 따른다.

raw=cleaning/service=geeknews_tread/year=2016/month=04/day=21/status=success/125201.csv

### 구성 규칙

{stage_key}={stage_value}/
service={service}/
year={YYYY}/
month={MM}/
day={DD}/
status={status}/
HHMMSS.csv

---

## 3. 설계 원칙

### 1. Enum 사용
- stage, status는 Enum으로 관리
- 문자열 오타 방지

### 2. 경로 키는 상수로 관리
- "year", "month" 같은 문자열을 코드에 직접 쓰지 않음

### 3. 시간은 한 번만 생성
- run_time을 기준으로 전체 처리

### 4. 책임 분리
- 경로 생성과 파일 저장 분리

# 📁 common/constant.py

```python
from enum import Enum


class Stage(Enum):
    CLEANING = "cleaning"


class Status(Enum):
    SUCCESS = "success"
    FAIL = "fail"


class PathConst:
    STAGE_KEY = "raw"
    SERVICE_KEY = "service"
    YEAR_KEY = "year"
    MONTH_KEY = "month"
    DAY_KEY = "day"
    STATUS_KEY = "status"
    CSV_EXT = ".csv"
```

---

# 📁 common/utils_time.py

```python
from datetime import datetime


def get_run_time() -> datetime:
    """실행 기준 시간을 생성"""
    return datetime.now()


def format_hhmmss(dt: datetime) -> str:
    """HHMMSS 형태 문자열 반환"""
    return dt.strftime("%H%M%S")
```

---

# 📁 common/utils_path.py

```python
from datetime import datetime
from pathlib import Path

from common.constant import PathConst, Stage, Status
from common.utils_time import format_hhmmss


def build_csv_path(
    stage: Stage,
    service: str,
    status: Status,
    run_time: datetime,
) -> Path:
    """CSV 저장 경로 생성"""

    file_name = f"{format_hhmmss(run_time)}{PathConst.CSV_EXT}"

    return Path(
        f"{PathConst.STAGE_KEY}={stage.value}"
    ) / (
        f"{PathConst.SERVICE_KEY}={service}"
    ) / (
        f"{PathConst.YEAR_KEY}={run_time.year:04d}"
    ) / (
        f"{PathConst.MONTH_KEY}={run_time.month:02d}"
    ) / (
        f"{PathConst.DAY_KEY}={run_time.day:02d}"
    ) / (
        f"{PathConst.STATUS_KEY}={status.value}"
    ) / file_name
```

# 📁 common/utils_file.py

```python
from pathlib import Path
import pandas as pd


def save_csv(df: pd.DataFrame, path: Path) -> Path:
    """CSV 파일 저장"""

    path.parent.mkdir(parents=True, exist_ok=True)
    df.to_csv(path, index=False, encoding="utf-8-sig")
    return path
```

## 5. 전체 사용 예시

```python
from datetime import datetime
import pandas as pd

from common.constant import Stage, Status
from common.utils_path import build_csv_path
from common.utils_file import save_csv

run_time = datetime(2016, 4, 21, 12, 52, 1)

df = pd.DataFrame([
    {"title": "example", "url": "https://example.com"}
])

path = build_csv_path(
    stage=Stage.CLEANING,
    service="geeknews_tread",
    status=Status.SUCCESS,
    run_time=run_time,
)

saved_path = save_csv(df, path)

print(saved_path)
```

## 6. 최종 정리

공통 모듈은 아래 4개로 시작한다.

common/
  constant.py
  utils_time.py
  utils_path.py
  utils_file.py

각 역할:

- constant.py  
  Enum + 경로 상수 정의

- utils_time.py  
  실행 시간 생성 및 HHMMSS 변환

- utils_path.py  
  저장 경로 생성

- utils_file.py  
  CSV 저장

이 구조를 기준으로 크롤링 / 전처리 / DB 적재 단계에서 공통 규칙을 유지한다.
