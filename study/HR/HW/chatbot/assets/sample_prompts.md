# 📚 chatvot 프롬프트 샘플 라이브러리

이 문서는 `chatvot` 앱 사용 시 참고할 수 있는 유용한 프롬프트와 Few-shot 예시 가이드입니다.

---

## 1. 단답 화면 (Short Answer) 추천 조합

### [개념 설명 + 쉽게]
- **질문**: "양자역학의 중첩 원리를 초등학생도 이해할 수 있게 설명해줘."
- **효과**: 복잡한 개념을 비유를 통해 쉽게 풀어서 설명받을 수 있습니다.

### [코드 작성 + 자세히]
- **질문**: "파이썬에서 리스트 컴프리헨션을 사용하여 1부터 100까지의 짝수만 추출하고 각 값을 제곱하는 코드를 작성하고 주석을 달아줘."

---

## 2. Few-shot 예시 추천 (Persistence 테스트용)

### [감성 분석 및 대응]
- **예시 1**: 
    - 입력: "배송이 너무 늦어서 짜증나요."
    - 출력: "불편을 드려 정말 죄송합니다. 배송 상황을 즉시 확인하여 보상 방안을 안내해 드리겠습니다."
- **예시 2**:
    - 입력: "제품 품질이 기대 이상이에요!"
    - 출력: "만족스러운 경험이 되셨다니 정말 기쁩니다! 앞으로도 더 좋은 품질로 보답하겠습니다."

### [특정 스타일 번역]
- **예시 1**:
    - 입력: "Apple"
    - 출력: "🍎 사과 (Apple)"
- **예시 2**:
    - 입력: "Banana"
    - 출력: "🍌 바나나 (Banana)"

---

## 3. 하이퍼파라미터 팁 (Temperature 0.1 모드)

현재 앱은 기본적으로 **Temperature 0.1**로 설정되어 있습니다. 
- **0.1**: 정답이 명확한 작업(요약, 번역, 코드 작성)에 유리하며 일관성 있는 답변을 줍니다.
- **1.0 이상**: 시 쓰기, 아이디어 브레인스토밍 등 창의적인 작업 시 사이드바에서 값을 높여보세요.
