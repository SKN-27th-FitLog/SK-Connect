# CharacterTextSplitter

- 단순하고 직관적
- 빠른 처리
- 명확한 분할 기준 : 특정 구분자를 명확하게 지정하여 분할 가능

- 분리 방법
		1. 우선 `seperator(기본: \n\n)` 기준으로 문서를 `split`
			- 문서를 문단단위로 분리
			- => 최소단위
		2. 각 문단 조각을 이어붙여 `chunk`를 만든다
			 - chunk의 길이 + 다음 문단 길이 <= chunk_size면 계속 붙인다
			 - 초과하면 새로운 chunk를 만든다
		3. 문단이 chunk_size보다 커도 문단 자체가 하나의 chunk가 된다
			- chunk_size보다 작은 chunk를 만들려 하지 않음
			- 즉, separator로 나눈 문단은 최소 chunk단위
		4. chunk_overlap은 문자 기준으로 적용

```python
from langchain_text_splitters import CharacterTextSplitter

text_splitter = CharacterTextSplitter(
	#텍스트를 분할할 때 사용할 구분자 지정
	separator = '\n\n',
	#분할된 테스트 청크의 최대 크기를 지정한다
	chunk_size = 200,
	#분할된 텍스트 청크 간의 중복되는 문자 수를 지정한다
	chunk_overlap = 20,
	#텍스트의 길이를 계산하는 함수를 지정
	length_function = len,
	#구분자가 정규식인지 여부를 지정
	is_separator_regex = False,
)
```

# RecursiveCharacterTextSplitter
- 문맥 보존 강화 : 여러 구분자를 계층적으로 사용
- 다양한 텍스트 구조에 대응 가능
- 사용자 정의 구분자 목록을 통해 분할 전략 제어 가능
- 정확한 chunk_size 제어

- CharacterTextSplitter와 다르게 최대 크기보다 큰 청크가 생성될 수 없다

작동원리
1. 가장 큰 `separator("\n\n")`로 텍스트를 `split`한다.
2. `split`된 조각 중 `chunk_size`보다 큰 조각이 있으면 -> 다음 `separator("\n")`로 그 조각을 다시 `split`한다.
3. 그래도 길면 `"."` -> `" "` 순으로 더 작은 단위로 계속 `split`한다.
4. 모든 `separator`로 분해했는데도 `chunk_size`를 넘으면 -> `글자 단위("")`로 자른다.
5. 최종적으로 만들어진 조각을 `chunk_size(+overlap)` 기준으로 합쳐 `chunk`를 생성한다.
```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

text_splitter = RecursiveCharacterTextSplitter(
	# 청크 크기 설정
	chunk_size = 200, #매우 작게 설정하는 경우
	#청크 간의 중복되는 문자 수 설정
	chunk_overlap = 20,
	#문자열 길이를 계산하는 함수를 지정
	length_function = len,
	#구분자로 정규식을 사용할지 여부를 설정
	is_separatoro_regex = False,
	#(옵션) 한국어 문장 구분용 구분자 설정
	separators = [
        "\n\n",  # 문단
        "\n",    # 줄바꿈
        r"(?<=[.?!])\s+",  # 영어 문장
        r"(?<=[다요죠음함임니다])[\.\?!]?\s+",  # 한국어 종결 표현
        " ",      # 단어
        "",       # 최후의 수단: 글자 단위
    ]
)

docs = text_splitter.split_documents(docs)
```
