# Document

document : 텍스트를 표준화된 형태로 다루기 위한 객체

| 속성             | 타입     | 설명      | 예시                                     |
| -------------- | ------ | ------- | -------------------------------------- |
| `page_content` | `str`  | 문서 내용   | `"LangChain is powerful"`              |
| `metadata`     | `dict` | 문서 부가정보 | `{"source": "manual.pdf", "page": 12}` |
## Document 생성하기

```python 
from langchain_core.documents import Document

documents = [
	Document(
		page_content = 'Hello, world',
		metadata = {'source':'https://example.com'}
	)
]

print(f'document의 수 : {len(documents)}')
```
> document의 수 : 1


## Document 데이터 확인하기

```python
print(f"첫번째 문서의 데이터 확인: {documents[0].page_content}")
print(f"첫번째 문서의 메타정보 확인: {documents[0].metadata}")
print(f"첫번째 문서의 메타정보 > source 확인: {documents[0].metadata['source']}")
```

>첫번째 문서의 데이터 확인: Hello, world!
>첫번째 문서의 메타정보 확인: {'source': '[https://example.com](https://example.com/)'}
>첫번째 문서의 메타정보 > source 확인: [https://example.com](https://example.com/)


# TextLoader

일반 텍스트 파일(.txt)를 읽어 Document리스트로 변환

## 파이썬을 이용한 txt 파일 확인

```python
# data 폴더에 있는 rag-keywords.txt 파일을 로드합니다

file_path = "./data/rag-keywords.txt"


# 파일 열기 및 읽기

with open(file_path, 'r', encoding='utf-8') as file:
    contents = file.read()
    
# 내용 출력

print(f"[일부 앞부분 내용 확인]\n{contents[:300]}")
```


# Loader 생성하기

## TextLoader 객체 생성

```python
print(f"저장된 파일의 위치정보 : {file_path}")

from langchain_community.documnet_loaders import TextLoader
# TextLoader는 텍스트 파일을 로드하는 Langchain의 기본 로더
loader = TextLoader(file_path, encoding = 'utf-8')
```

## 파일 로드

```python
# load() 메서드를 호출하면 파일의 내용을 읽어서 Document 객체의 리스트로 반환함
documents = loader.load()

print(f"로드된 파일의 수: {len(documents)})
```

# DirectoryLoader
- langchain의 문서 로더 중 하나
- 지정한 디렉토리 안의 모든 파일을 자동으로 찾아서 각각 document로 변환

## 다중 파일 로드
``` markdown
| 옵션            | 설명               | 예시                           |
| --------------- | ---------------- | ------------------------------- |
| `glob`          | 불러올 파일 패턴 지정 | `"**/*.txt"` → 모든 하위 폴더의 txt 파일|
| `show_progress` | 진행 상황 표시 여부     | `True` → tqdm 형태의 로딩바 표시  |
| `loader_cls`    | 사용할 하위 로더 클래스 지정 | `TextLoader` 등              |
| `loader_kwargs` | 하위 로더에 전달할 인자    | `{"encoding": "utf-8"}` 등   |
```

```python
from langchain_community.document_loaders import DirectoryLoader
from langchain_community.document_loaders import TextLoader
# DirectoryLoader : 폴더 전체를 다루는 범용 로더
# TextLoader : 개별 텍스트 파일을 읽어오는 전용 로더


loader = DirectoryLoader("./data", glob="*.txt", show_progress=True,
                         loader_cls=TextLoader, loader_kwargs={"encoding": "utf-8"})
#./data : 문서를 찾을 대상 디렉토리 경로
# glob="*.txt" : 해당 디렉토리에서 확장자가 .txt인 파일만 골라내기
# show_progress= True : 파일이 많을 경우 로딩 과정을 progress bar로 시각화
#loader_cls = TextLoader : 디렉토리 안의 개별 파일을 처리할 때 사용할 구체적인 클래스 지정... 여기서는 텍스트 파일을 처리하므로 TextLoader사용
#loader_kwargs = {"encoding": "utf-8"}  :  TextLoader에 전달할 추가 설정값...

  
# 조건에 맞춰 모든 파일을 읽어들인다
#결과물은 Document 객체들의 리스트 형태로 documents변수에 저장됨
documents = loader.load()
print(f"로드된 파일의 수: {len(documents)}")
```
