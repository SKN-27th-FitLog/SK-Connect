- Json 파일을 읽어서 각 항목을 Document 객체로 변환해주는 문서 로더
- json 데이터의 특정 필드를 page_content로 지정하여 llm이 이해할 수 있는 텍스트 문서 형태로 바꿔주는 역할


# JSON file with jq schema 생성

| 인자            | 타입       | 설명                       | 예시                        |
| ------------- | -------- | ------------------------ | ------------------------- |
| file_path     | str      | 불러올 JSON파일 경로            | "data.json"               |
| jq_schema     | str      | 문서 내용으로 가져올 JSON경로(jq문법) | ".[] .content"            |
| text_content  | bool     | JSON값을 텍스트로 처리할지 여부      | False                     |
| metadata_func | callable | 각 문서의 metadata생성 함수      | lambda x: {"id": x["id"]} |
- jq_schema 
	- json 구조 안에서 어떤 데이터를 꺼낼지 지정하는 경로
	- 리눅스의 jq명령어 문법을 그대로 사용

# Extracting metadata 생성

- metadata_func를 정의하면 jq_schema로 지정한 본문외의 다른 필드를 Document객체의 metadata속성에 담을 수 있음

```python
#jq_schema

from langchain_community.documnet_loader import JSONLoader

loader = JSONLoader(
	file_path = file_path,
	# tourist_attractions 배열의 각 요소를 반복
	# | : 앞의 결과를 다음 명령으로 넘김
	# "\(.name): \(.description)(팁: \(.tip))" : 문자열 포맷팅
	jp_schema = r'.tourist_attractions[] | "\(.name): \(.description)(팁: \(.tip))"',
	text_content = False
)

documents = loader.load()

print(f"로드된 파일의 수: {len(documents)}")
```


```python
# metadata
def metadata_func(record: dict, metadata: dict) -> dict:
	metadata["travel_foods"] = [food["dish"]for food in record. get("local_cuisine", [])]
	
loader_desc = JSONLoader(
	file_path = file_path,
	jq_schema : '.', #딕셔너리 객체 반환 -> json.dumps()로 변환됨
	text_content = False,
	metadata_func= metadata_func
)

docs = loader_desc.load()

for i, doc in enumerate(docs):
    print("="*70)
    print(f"Document {i+1}:")
    print(f"   - 타입: {type(doc)}")
    print(f"   - page_content 타입: {type(doc.page_content)}")
    print(f"   - metadata 타입: {type(doc.metadata)}")
    print(f"   - metadata 내용(travel_foods): {doc.metadata['travel_foods']}")
    print(f"   - metadata 전체 내용: {doc.metadata}")
    print(f"   - 내용 길이: {len(doc.page_content)} 문자")

    # JSON 문자열을 파싱한 후 ensure_ascii=False로 다시 출력하여 한글 표시
    import json
    content_dict = json.loads(doc.page_content)
    print(f"   - 내용 (한글 표시):")
    print(json.dumps(content_dict, ensure_ascii=False, indent=2))
    print()
```
