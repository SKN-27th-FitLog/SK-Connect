- RAG에서 PDF는 가장 흔한 데이터 소스 중 하나
- PDF의 텍스트 레이아웃, 표 구조, 이미지 포함 여부에 따라 정확한 자료 추출 품질이 크게 달라진다
- 따라서 문서 형태에 맞는 로더 선택은 RAG 전체 품질을 좌우하는 핵심 요소이다


- PyPDFLoader
	- 가장 기본적인 텍스트 중심 PDF로더
	- 가볍고 빠르지만 기능 제한
	- 단순 텍스트 문서에 적합
- PDFPlumberLoader
	- 표와 레이아웃 분석에 최적화된 로더
	- 테이블 추출 정확도 최고
	- 형식이 있는 보고서나 논문에 강함
- PyMuPDF4LLMLoader
	- 이미지, 텍스트, 구조를 가장 유연하게 처리하는 최신 로더
	- 텍스트 + 이미지 +구조까지 모두 지원
	- PDF 내부 이미지(Blob)완전 추출

상황별 로더 선택 가이드

	-텍스트 기반 단순 pdf : PyPDFLoader
	-표 구조 중심 PDF : PDFPlumberLoader
	-이미지.스캔 포함 PDF : PyMuPDF4LLMLoader
	 - 가장 범용적인 로더 : PyMuPDF4LLMLoader
